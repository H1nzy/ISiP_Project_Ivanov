# Техническое задание — «АИС Больница» (вариант 17)

**Название:** «АИС Больница». **Область применения:** сотрудники больницы; пользователи — врачи, медсёстры, регистраторы, бухгалтерия, администрация. **Назначение:** автоматизация учёта пациентов, приёмов, назначений и отчётности; система разворачивается на сервере в больнице с доступом по локальной сети. **Функциональные требования:** ведение картотеки пациентов, регистрация приёмов, оформление назначений, поиск информации, формирование отчётов. **Нефункциональные требования:** понятный интерфейс, надёжное сохранение данных, доступ только зарегистрированным пользователям, быстрая обработка запросов. **Требования к данным:** пациент (ФИО, дата рождения, контакты, номер карты), приём (дата, врач, пациент, диагноз), назначение (лекарство/процедура, дозировка, срок), пользователь системы (логин, хэш-пароль, роль). **Требования к интерфейсу:** форма авторизации, главное меню, формы пациентов, приёмов и назначений.
