## О проекте
Данный репозиторий содержит материалы по разработке автоматизированной информационной системы (АИС) для предметной области «Больница».

### Содержимое репозитория:
- `README.md` — описание проекта и данные студента.
- `analysis.md` — анализ предметной области (Практическая работа №1).
- `tz.md` — техническое задание (Практическая работа №2).
- `architecture.md` — описание архитектуры ПО (Практическая работа №3).
- `.gitignore` — настройки игнорируемых файлов.
